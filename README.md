# CSC584-Individual-Assignment-1

## Project Description
The My Profile Personal Registration Project is a web-based application developed for CSC584 Individual Assignment 1. It enables users to register and create a personal profile by entering their personal details, contact information and background through an interactive registration form. The application processes, validates, and displays the submitted user profile information clearly.

## Technologies Used
- Software: NetBeans IDE 8.2
- Frontend: HTML5, CSS3, JavaScript
- Backend: Java (Servlets/JSP) 
- Server: GlassFish 

## How to Run the Application
1. Prerequisites: Install NetBeans IDE and GlassFish.
2. Setup: 
   - Clone or download this repository.
   - Open the project in your NetBeans IDE.
3. Run:
   - Start the local web server (GlassFish).
   - Run the project from your IDE or open `http://localhost:8080/CSC584-Individual-Assignment-1/` in your web browser.
   - Fill out the personal registration form and submit to view the generated profile output.
